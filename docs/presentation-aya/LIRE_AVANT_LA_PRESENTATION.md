# Dossier de présentation du projet d’Aya
Préparé le 13 novembre 2026 pour le point d’avancement.

## Commencer
1. Lire Rapport_Aya_Decors_Concert_Virtuel.pdf.
2. Ouvrir Demonstration_guidee_Aya.html dans un navigateur. Elle fonctionne hors ligne ; les flèches permettent d’avancer et les notes aident à parler.
3. Pour la version interactive déjà lancée : http://127.0.0.1:5180/decors.html.
4. Si nécessaire, extraire tout ce dossier puis lancer Lancer_la_demo.cmd. Node.js est requis ; le lanceur recherche d’abord celui de Codex sur ce PC.
5. Ouvrir alors http://127.0.0.1:5182/decors.html et garder le terminal ouvert.

## Démonstration interactive
Montrer la scène Festival ; passer à Compacte ; revenir au Festival ; ajouter une enceinte ou une cabine ; modifier sa position et sa couleur ; régler un spot ; Enregistrer ; recharger ; Restaurer ; exporter puis réimporter.
Le JSON d’exemple contient la cabine de la démonstration. Export_personnel_Aya.json est une copie du fichier exporté par Aya, sans modification de l’original.

## Contenu
- Rapport illustré de 11 pages et synthèse académique de 2 pages.

## Limites à expliquer
Le plateau et les musiciens ont été réutilisés depuis le laboratoire ; l’atelier et ses décors modifiables constituent le nouveau travail.
L’export JSON est propre au prototype. L’intégration WAM JAM Party, les textures importées, les ports musicaux et les mesures Quest restent à réaliser.
Quatre scénarios navigateur passent ensemble ; le scénario de déplacement a réussi séparément après un dépassement de délai du passage complet.
Les nouveaux développements sont locaux : le commit Git reste bloqué par les permissions de l’index. Cette archive assure une sauvegarde, mais ne remplace pas un commit.

Aucune publication ni aucun envoi à l’encadrant n’a été effectué.
